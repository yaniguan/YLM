## Write these files (python 3.11, torch 2.10 CPU here, e3nn 0.6, transformers, rdkit, pandas available):

1. src/ylm_lm.py
   - IrrepsTokenizer: wraps Encoder (n_elements=100) -> per-atom irreps; produces "irreps tokens" for the LM:
     variant "A": invariant soft tokens per atom from IrrepsToText option A (queries = LM hidden states) — implement as an adapter:
     IrrepsAdapter(lm_dim, encoder irreps, option in {A,B,C}) inserted after layer k of a decoder LM: h <- h + gate * Linear(invariants(e_t)) where e_t = IrrepsToText(h_t, atom_irreps) using the repo's option A/B/C. Gate init 0 (tanh gate) so start == text-only model. invariants = scalars + per-irrep norms (parity-correct like the repo).
     Also a simpler "prefix" mode: per-atom invariant features projected to soft prefix tokens prepended to the sequence.
   - YLMCausalLM: builds a small GPT-2 (transformers GPT2Config, from scratch, configurable n_layer/n_embd/n_head) or loads a pretrained HF causal LM by name (e.g. Qwen/Qwen2.5-0.5B) and attaches adapters via forward hooks. mode in {"text","prefix","xattnA","xattnB","xattnC"}. Text mode has no adapter (report param counts for fairness). Supports multiple molecules per sample (mixtures): atoms of all species concatenated with a species-id + mole-fraction scalar embedding added to the l=0 input channel, OR pooled per species — pick something correct and documented; positions of different species offset by >cutoff so no cross edges.
   - Equivariance/invariance test: LM loss must be invariant to random O(3) rotation+translation of input coords for adapter modes (rotation for SO(3) exactness; check reflection too and report).
2. src/tasks/  (package)
   - tokenizer: character-level/regex SMILES+number tokenizer (self-contained, no downloads) for the from-scratch GPT; HF tokenizer for pretrained LMs.
   - qm9_pretrain.py: pretraining corpus from qm9_xtb.pkl + SMILES: text variants "smiles" ("<mol> SMILES </mol> E=... mu=[x,y,z]|mu|=..."), "smiles_xyz" (adds xyz coordinates as text, 2 decimals, in Angstrom). Irreps arms see SMILES text + geometry via adapter (no xyz text). Same molecules/splits for all arms (split by qm9_index, seed).
   - conformers.py: RDKit ETKDG + MMFF conformer for a SMILES (handles ions/salts with multiple fragments; cache to data/cache/conformers.pkl; deterministic seed); returns Z, pos in bohr.
   - calisol.py: load/clean CALiSol, mixture representation, prompt text "salt=LiPF6 c=1.0 mol/L T=298.2K solvents EC:0.50 DMC:0.50 ratio=molar", target log10(k+1e-3) (also report MAE in mS/cm). Splits: random, and leave-formulation-group-out (group = salt + set of solvents) to test generalisation. Also leave-DOI-out option.
   - reddb.py: targets reaction_energy (redox), reactant_solubility, reactant_lumo (reduction proxy), reactant_homo (oxidation proxy); scaffold split (RDKit Murcko) + random split. Subsample option.
   - mp_battery.py: as above.
   - sft.py: instruction QA builder for post-training: "Q: what is the LUMO of <mol>? A: -0.123" from QM9/RedDB/CALiSol train splits only; answer tokens only in loss. Also a DPO preference-pair builder (chosen = true numeric answer, rejected = perturbed answer) and a simple DPO loss implementation.
3. scripts/20_pretrain_lm.py: args --arm {smiles,smiles_xyz,prefixA,xattnA,xattnB,xattnC} --tokens_budget (matched-compute: stop at fixed number of training TOKENS seen incl. prefix tokens counted; also log FLOPs estimate) --model {tiny,small,hf:<name>} --init_encoder <ckpt optional> --device --out runs/<name> --resume (checkpoint every N steps incl optimizer, RNG, step; resume from latest) --profile_dir. Outputs metrics.json: val loss/ppl on held-out molecules, ppl split by token type (SMILES tokens vs numeric property tokens), numeric property MAE via greedy decode on N val molecules (parse number), params, tokens seen, wall time.
4. scripts/21_posttrain.py: SFT (and --dpo) from a pretrained arm checkpoint; same budget across arms; eval exact numeric MAE on held-out questions; --resume.
5. scripts/22_downstream_eval.py: for each task in {calisol, reddb, mp_battery} and arm: (a) frozen-LM probe: mean-pooled hidden state -> ridge regression (sklearn if available else closed-form torch); (b) fine-tune: LM + regression head, small epochs. Metrics: MAE, RMSE, R2, Spearman; 3 seeds; bootstrap 95% CI on test. Also non-LLM baselines: RF / ridge on RDKit Morgan fingerprints (mixture = fraction-weighted) + T + c. Writes results JSON + markdown table.
