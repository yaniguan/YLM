01 / The method

Invariant attention weights.
Equivariant tensor values.

Standard multimodal bridges flatten 3D geometry into rotation-invariant numbers before text can read it. YLM keeps directional spherical harmonics intact all the way through cross-attention.

01

Query with invariants, route to atoms

Frozen question tokens from MiniLM or MatSciBERT score each atom using only rotation-invariant norms and even scalars, so attention weights α_ti never drift when the molecule rotates or reflects.

02

Transport 0e, 0o, 1o, and 2e irreps

Selected atoms pass full Wigner-D equivariant values to each token. Option A uses linear equivariant values; Option B adds same-irrep directional inner-product keys; Option C adds a text-weighted Clebsch–Gordan self-product.

Plug-and-play 3D backbones

Mount on lightweight built-in e3nn layers (1–2 MB checkpoints) or pretrained MACE-MP-0, MACE-OFF23, and NequIP / Allegro force fields with periodic crystal cells.

02 / Quantitative benchmarks

Does language routing generalize?

Evaluated on 84,757 dipole and atom-force questions across 20,000 QM9 molecules under 32 random 3D rotations per test question, plus held-out phrasings and multi-rank ablations.

TensorQA-v0 · 5 seeds

6.6× lower force MAE with text.

Audit 2

Chiral enantiomers & Ouroboros 2D-to-3D bridge

Pairwise distances are identical on left-handed (R) and right-handed (S) mirror molecules. YLM’s parity-odd 0o head separates mirror twins and connects directly to 2D stereochemical drawings from ouroboros-ocsr.
